# Tactica: Chess Tactics Trainer

Turns your own chess mistakes into puzzles. Import games from Chess.com or Lichess, analyse them on-device with Stockfish, and train on the positions you got wrong. Includes principle drills and exact king-and-pawn endgame drills.

- `Tactica.html` is the whole app (single file, works offline).
- `src/` holds the template, build script and the puzzle-library generators.
